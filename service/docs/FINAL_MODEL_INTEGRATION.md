# 현재 모델과 서비스 연결

2026-10-17, 모델 `11643ae`의 공개 조회 함수와 저장소에 포함된 전국 I5 번들을 연결했다. 모델 계산 코드와 기존 스냅샷은 보존했다.

## 호출 흐름

```text
FinalModelApp → GET /api/model/survey-area → survey_area_index.query()
             → GET /api/model/behavior    → query.query()
             → GET /api/model/status     → 두 번들의 검증·준비 상태
             → GET /api/model/regions    → 실제 I5 결과의 시도·시군구 목록
```

서비스 기본 모드는 `final`이다. 코드 위치는 `DONGHAENG_MODEL_ROOT`(기본 형제 `model`)로 지정한다. 모델의 훈련용 의존성을 설치하거나 서비스를 시작할 때 모델을 다시 학습하지 않는다.

| 자료 | 공간·집단 | 시간 | 화면 |
| --- | --- | --- | --- |
| I5 | 전국 17개 시도, 20세 이상 전체 인구구성 | 2025년 7~12월 | 서울 427개 동 지도, 전국 읍면동 목록·5영역 점수·인구비중 |
| V3 활동 | 5자리 시군구, 남/여 × 20/30/40/50/60세 이상 | 8~12월의 전월 비교 | 일평균 SKT 유동·카드 결제 건수, 변화율, Q/H/T·강건 통계 |
| C3 | 모델이 실제로 연결한 카드 성·연령 관측 | 과거 7~9월 동일요일 기준, 10~12월 비교 | 활동 패널의 별도 참고자료 |

I5는 지역 직접 설문·개인 고립확률·고립률이 아니다. 월별 변화는 인구구성 변화다. 활동 10집단을 I5 6집단으로 강제 조인하지 않는다. C3는 같은 카드 원자료에 다른 기준을 적용한 자료이며 독립 원천으로 세지 않는다. 결측값·미계산 후보는 각각 `null`로 유지한다.

현재 HTTP 범위는 모델의 두 주요 조회 함수다. 전국 설문 6집단 원표(`survey_query`), C1/M1/M2 외부 맥락(`external_query`), 동별 SKT 원출력과 에이전트 조사 워크플로는 새 화면/API에 추가하지 않았다.

## 번들 설정과 실패 처리

활동 번들은 `FINAL_MODEL_BUNDLE`로 지정한다. I5는 `I5_BUNDLE_PATH`를 우선하고 `SURVEY_AREA_BUNDLE`을 호환 별칭으로 받는다. 명시 경로가 없으면 I5는 `model/data/i5/national_2025`를 가장 먼저 읽는다. 이 경로가 없을 때만 기존 runtime·model outputs 포인터를 탐색한다. 활동은 runtime·model outputs의 `latest.json`을 탐색한다. 발견한 기본 번들이 손상됐거나 명시 경로가 잘못되면 다른 자료로 전환하지 않는다. 과거 두 지역 runtime 포인터가 전국 I5를 가리지 않는다.

조회 시 모델의 전체 출력 해시 검사를 수행하고, 서비스에서 필수 출력의 manifest 등록·계약 버전·전체 레코드 스키마·중복 키·C3 참조 존재를 검사한다. 전국 23,282행의 스키마 검사 결과는 동일 경로·출력 해시에 한해서 재사용하며 파일 해시는 매 요청 다시 검증한다. 실패·합성·변조 번들은 503, 잘못된 지역·연령·월·페이지 요청은 422, 유효한 조건에 관측이 없으면 200과 빈 목록을 반환한다. `/api/health`의 HTTP 200은 프로세스 응답 가능 상태이며 자료 준비 여부는 `sources.*.ready`를 확인해야 한다.

`prepare_final_model.py`는 기본 전국 번들을 검증한다. `--source`를 명시할 때만 과거 동결 집계를 재생성한다. 서울 경계는 정확한 행정동 코드·시군구 이름을 대조하고, 공식 동 이름의 `제` 번호 표기와 가운데점 차이만 허용한다. 서울 427개가 모두 연결되며 다른 시도는 목록과 상세값으로 제공한다. 시군구 목록은 실제 산출값에서 만들고, 읍면동 탐색 UI에서는 하위 구와 인구가 중복되는 상위 시 합계(직속 동 0개)를 제외한다. 상위 시 참고값은 API에서 별도 조회할 수 있다.

시도 조회는 `province_code`로 모델의 검증된 행을 먼저 필터링한 뒤 페이지를 나눈다. 프런트는 `next_offset`이 끝날 때까지 읽고 실행 ID·총 행 수가 중간에 바뀌면 재조회를 요청한다. `/api/research/i5`는 같은 I5 API의 별칭이며 `dong_code`만 지정하면 행정동 조회를 선택한다.

## 실행과 배포 경계

개발 프런트는 `/api`를 `127.0.0.1:8000`으로 프록시한다. 별도 호스팅에서는 `VITE_MODEL_API_BASE_URL`과 CORS 설정이 필요하다. Docker는 모델 Git에 포함된 전국 I5 데이터를 함께 복사한다. 별도 행동 번들은 읽기 전용으로 마운트한다. 원자료·상세 행동 번들을 프런트 정적 파일에 넣지 않는다.

이전 `research`, `research-api` 화면과 링크는 제거했다. 옛 주소는 현재 모델 화면으로 연결하고 mode 쿼리를 지운다. `mock`, `api` 합성 시연은 보존한다. 이전 백엔드는 `requirements-legacy.txt`와 전국 I5를 지원하는 최신 `model`, `agent`를 필요로 한다. CI는 새 모델용 서비스 검사와 전체 프런트 검사를 수행한다. Pages 워크플로는 `final` 및 저장소 변수 `VITE_MODEL_API_BASE_URL`을 사용하며 이번 작업에서 원격 배포하지 않았다.

## 로컬 검증

- 실제 전국 I5: 시·구·군 단위·월 1,584행, 읍면동·월 21,698행 API 조회. 서울 25개 구·427개 동, 경기도 500행 초과 페이지, 부산 동 조회 검증.
- 서울 기존 경계 427개와 실제 I5 427개를 대조해 모든 동에 참고값이 연결됨을 확인. API 37개 통과·선택 의존성 관련 4개 모듈 제외, 프런트 25개 통과·빌드 통과.
- 활동: 합성 테스트 번들로 필터·페이지·null·C3 기준 분리·해시 및 스키마 거부를 검사. 현재 체크아웃에는 실측 활동 번들이 없어 실측 활동 조회는 대기 상태.
- API 자동 검사는 FastAPI TestClient를 사용함. 실행 환경의 포트 사용 제한으로 백엔드 재시작은 사용자가 수행했으며, 이후 Chrome의 실제 서비스 화면에서 서울 427개 동과 전국 시도 목록, 부산 조회를 확인함.
- 새 의존성의 별도 설치·Docker 이미지 빌드·원격 CI·원격 배포는 수행하지 않음. 로컬 설치 Python 라이브러리로 테스트함.
- 과거 `.artifacts/final-model/preview.html`은 이전 두 지역 화면 검증용 파일이며 현재 전국 연결의 근거로 사용하지 않음.

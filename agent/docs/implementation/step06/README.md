# Step 06 — HERMES Complete HTML 교체

2026-10-25 사용자 제공 `C:/Users/jssh2/Downloads/HERMES_Complete.html`을 새 화면 기준으로 적용했다. Step 05의 React 화면을 더 다듬는 대신 완성 HTML의 구조·스타일·대화 이력·정책 만들기·기록/보고서를 그대로 사용한다.

## 화면과 실행

- 기본 진입 `/` → `/hermes-complete.html`로 이동. 기존 화면은 `/?mode=legacy`에 남긴다.
- 원본 Downloads 파일은 변경하지 않는다. `service/frontend/scripts/import_hermes.py`가 연결 부분을 명시적으로 변환해 `service/shared/hermes-complete.html`을 생성한다.
- Vite 개발/빌드 모두 같은 파일을 제공한다. 기본 상대 주소의 API 프록시를 이용한다.
- 별도 iframe으로 감싸지 않아 원본의 화면 높이·주소 상태·브라우저 인쇄 동작을 유지한다.

## 실제 연결과 보관 자료의 구분

| 기능 | 연결 |
|---|---|
| 지역 목록·지도 I5·활동 비교 | 기존 `/api/model/*` 서버 |
| 대화의 I5·활동 근거 | 첨부 UI의 근거 계약에 서버 응답을 연결 |
| 복지 검색·추천·대화 속 추천 | `/api/model/welfare` → 기존 LangGraph → ERD 임시 DB |
| 전국 기준값·행정동 통신·보조 맥락 | 첨부 HTML의 해시 검증된 보관 자료. 현재 서버 신규 조사로 표현하지 않음 |
| 대화·검토·후속 조치·정책 초안 | 브라우저 localStorage. 별도 서버 저장이나 기관 전송 없음 |

서버의 I5/활동 조회 또는 추천이 실패하면 오류를 표시한다. 저장본의 추천으로 조용히 바꾸지 않는다. 지역이 없는 전국 범위의 추천은 지역 선택을 안내한다. 전체 집단은 각 성·연령을 따로 실행하고 같은 사업을 묶되 집단별 근거를 남긴다. 읍면동 선택에서는 추천이 상위 시군구 근거임을 코드와 근거 ID로 유지한다.

원본 HTML의 전국 평균 초과 여부에 따른 분야 연결은 사용하지 않는다. 사용자 승인 사항대로 기존 `research-context-v1`의 활동신호별 경로와 관련 I5 참고값을 이용하며 세부 고저 임계값은 미확정이다.

## 검증

- TypeScript 검사 통과.
- 프런트 시험 30개 통과: 기존 25개 + 전체 HTML 스크립트 문법, 동→시군구 추천 범위, 집단별 근거 유지, 서버 실패 시 대체 금지, 전국 범위 선택 안내 5개.
- 브라우저 질문 `강남구 2025년 8월 남성 20대 활동을 분석하고 복지를 추천해 줘`: 통신 -4.51%, 카드 -0.34%, 추천 2건과 실제 근거 ID 표시 확인.
- Vite 프로덕션 빌드 통과. 새 대화 → 복지 화면에서 강남구·202508·남성·20대 선택 유지 및 기록·보고서의 근거 표시 확인.
- 원본의 대화 복원 시 선택 조건 초기화 문제를 수정했다. 홈과 복지 화면 캡처는 `service/docs/screenshots/hermes-complete-*.png`.

## 제약

추천 사업은 가상 DB이며 공식 원문·실제 신청 링크가 없다. 원본 화면의 운영사업 표기를 이에 맞게 수정했다. 대화는 규칙 기반 해석이며 자유형 LLM과 외부 원인 조사는 아직 연결하지 않았다. 정책 만들기는 검토용 초안으로만 제공한다. 여러 기기의 공동 기록·기관 업무 처리는 후속이다.

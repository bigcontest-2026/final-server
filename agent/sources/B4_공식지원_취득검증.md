고립청년 지원은 정서적 또는 물리적 고립 기준과 지속기간을 함께 확인한다. 은둔청년 지원은 집 중심 생활, 지속기간, 경제활동·구직·학업 조건을 함께 확인한다. 지역 집계 지수만으로 개인의 지원 자격을 확정하지 않는다. 개인 응답 원자료는 이 취득 작업 및 외부 전송에 사용하지 않았다.

## 실패와 대안

1. 공공데이터포털 HTML의 JSON-LD 다운로드 URL은 CSV 대신 `11.png`를 반환했다. HTTP 200만으로 성공 처리하지 않았다. 공식 다운로드 버튼의 공개 JSON 응답이 반환한 최신 파일 ID를 따라 실제 CSV를 확보했고 인코딩·행·열·ID·빈칸을 검증했다.
2. 서울 청년지원의 단축 주소는 `mainA.do`로 이동하는 393 bytes 화면을 반환했다. 공식 홈페이지 메뉴에 있는 전체 파라미터 URL로 상세 원문을 취득했다.
3. 청년지원 신청 단계는 로그인이 필요하다. 상세 취득 성공과 실제 접수 가능성을 분리하고 접수 상태를 `unknown`으로 보존했다.
4. 춘천의 열림 프로그램은 공식 시정 소식지의 과거 안내만 확보했다. 현재 접수 중으로 만들지 않고 최근 공개 기관 상담 상세를 별도 후보로 선택했다.

## 저장·공개 범위

- 서비스 후보 계약: `service/shared/support/manifest.json`
- 검색 목록: `service/shared/support/catalog.json`, 실제 원본 `welfare_catalog_20260819.csv`
- 전체 원문과 전체 텍스트: `service/backend/evidence/support/raw/`, `text/` (로컬 증빙, Git 제외)
- 취득 기록: `acquisition_ledger.json`; 해시·문구 검증: `support_source_verification.json`
- 권리 기록: `rights_manifest.json`; 재취득 도구: `acquire_official_sources.py`

Vite 공개 폴더에는 전체 HTML·전체 텍스트를 넣지 않는다. 외부 모델에는 사실 조건·짧은 인용·URL만 전달한다. 서울 일반가구 페이지는 공공누리 4유형을 표시하며, 서울 청년 페이지와 춘천 기관 페이지의 원문 재배포 허락은 확정하지 않았다. 전체 원문 공개·제출·학습 권리와 자료별 이용조건은 별도 확인 상태다.

## 완료 범위

공식 CSV 실제 취득, 상세 4건 구조화, 원문 해시와 최소 근거문구의 일치 검증은 완료했다. 통합 파일럿은 개인 자격의 허위 확정 금지, 타지역·종료 후보 제외, 근거 연결을 포함한 자동 불변조건 93/93을 통과했다. 개발 반례 및 캡처 재생 결과이며 사용자 잠금 평가와 구분한다. 키가 필요한 중앙/지자체 상세 API 성공, 실제 로그인 접수, 기관 상담·지원 연결은 미완료다.

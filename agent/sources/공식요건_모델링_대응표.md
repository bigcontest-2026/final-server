# 대회 공식 요건과 현재 제출 근거

공식 공개 홈과 공지 32·33·34를 다시 취득했다. [제출 안내](https://www.bigcontest.or.kr/#apply)는 발표자료 형태의 이메일 제출과 기타 심사자료 제출 가능을 안내한다. 이번 작업에서는 신청·제출·기관 연락을 하지 않았으며 날짜별 실행 목표를 추가하지 않았다.

[공지 33](https://www.bigcontest.or.kr/#notice)은 주제설명자료와 테이블 정의서 첨부를 계속 제공한다. 새 PDF 다운로드는 `text/html` 오류 화면을 반환해 신규 PDF 취득이나 기존 사본과의 바이트 일치를 주장할 수 없다. 기존 공식 사본 `tmp/history_audit/contest_topic_260907.pdf`의 8~10페이지를 다시 읽었다. 해시는 `27762a32e84a0996f9e54ce8499541dbfe3ceb547bc408a0237253d22a8f0ae9`다. 공개 홈·공지 목록·공식 도메인 검색 범위에서 본 프로젝트의 모델링 준수 해석을 해결하는 최신 FAQ는 찾지 못했다.

주제 PDF는 LLM 활용을 선택 요소로 두지만 최소 성과물에 예측·분류 모델링 결과를 명시한다. 따라서 도구가 동작한다는 결과만으로 모델링 요구도 충족했다고 처리하지 않는다. 공식 문의가 필요한 핵심 쟁점은 **지역 집계 조사도구와 실패한 고립 실험·보조 활동예측을 함께 제시하는 구성이 해당 모델링 요구를 충족하는가**다. 문의 전송은 사용자의 별도 지시가 필요하다.

권리와 실제 취득 여부는 `rights_manifest.json`, `acquisition_ledger.json`에서 관리한다. 공개용 근거 패키지에는 개인 설문 원자료나 권리 미확정 원문 전체를 자동 포함하지 않는다.

# C3 20세 이상 10집단 기준선

`submission/code/vendor/C3_Shinhan_baseline`의 C3 1.1.0 코드·설정·공휴일 달력을 보존한 오프라인 계산 모듈이다. `hermes-complete/model/final_model`의 V3/C3 분리 구조를 유지한다.

20·30·40·50대·60세 이상을 지원한다. 60·70·80·90대는 원본 중복 검사 후 일별 건수·금액으로 합산하고, 그 합계로 7~9월 같은 요일 기준선을 계산한다. 10~12월 평가에만 연결하며 `60+`는 V3 `60GU`에 대응한다.

재계산에는 별도로 공급된 신한 원자료가 필요하다. 집계값·변화율을 다른 연령에서 복제하지 않는다. 실행 방법과 게시 전 검증은 [C3 연령 확장 문서](../../docs/C3_AGE_EXPANSION.md)를 참고한다.

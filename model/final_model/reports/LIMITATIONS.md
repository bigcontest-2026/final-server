# 해석과 재현성의 한계

개인 고립 정답·개인 연결키가 없다. 활동변화 후보는 고립 확률·진단·원인·복지 자격이나 사람 수가 아니다. 지역별 I5는 전국 조사 집단값과 MOIS 인구구성으로 계산한 참고값이며 지역 직접 조사나 지역 고립률이 아니다.

SKT merge의 최초 공간 조인 경계·CRS, 기대 관측 격자·공급 규칙이 공식 검증되지 않았다. 9→10월 경계 변화 hold를 유지한다. 현재 Robust 후보 2개는 10월 춘천 20대 남녀에 있어 경계 변화와 함께 해석해야 하며 운영 경보로 전환하지 않는다. 카드 결측·마스킹·업종 세부분류 규칙도 미확인이다.

C3 기본 대상은 20/30대, 7~9월 기준·10~12월 월별 평가다. 전년 동기·연간 계절성·과거 공표시점 복원은 수행하지 않았다. 같은 카드 원천의 다른 기준선이므로 독립 검증자료가 아니다. C1 서울 분기값은 춘천·월 실측으로 복제하지 않고 M1/M2 주차도 공식 매핑 없이 월별로 합치지 않는다. M3 공간 정렬은 미검증이다.

전달받은 원본 V3 100키의 관측값·판정·품질 및 동 SKT는 직접 대조했다. 다른 모델의 원 팀 최종 출력 전체가 재현됐다는 뜻은 아니다. 원본 합성·달력·카드 범위 실험은 해시가 검증된 기존 기술 근거다. 이번에 새 합성 실험을 실행하거나 실제 고립 탐지 성능을 검증하지 않았다. 달력 대체 시나리오도 공휴일 효과를 인과적으로 보정한 실측값이 아니다.

로컬 보완 코드는 저장 관측의 행동 100행·C3 월요약 880행 재계산, C3 연결 24셀 회귀, 완료 후 조회 및 경계조건 테스트로 확인했다. 새 코드로 SKT·신한 전체 원자료 집계·학습을 다시 반복한 것은 아니다. 기존 실측 번들 47개 파일과 최신 포인터는 보존했다.

깨끗한 checkout에는 원자료·실측 출력·외부 실험 코드가 없다. 설정 경로 외에 data_root의 형제 C1 코드와 M1/M2/M3 지정 실행 디렉터리도 필요하다. 필요한 파일과 실행 순서는 [README](../README.md)에 명시한다. 기존 전달 ZIP에는 이번 로컬 보완 코드가 포함되지 않는다.

실제 agent/service 연동·HTTP·LLM·정책 추천과 공동 최종 승인·버전 동결은 아직 수행하지 않았다. 현재 상태는 모델 병합 구현 완료·로컬 검수 보완 완료·공동 확정 대기다.

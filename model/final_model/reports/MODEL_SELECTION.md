# 최종 모델 선정과 소스별 역할

V3의 전월 변화 Q/H/T·양원천 감소·강건 후보를 기본 행동 모델로 유지하고 C3의 고정 7~9월 동일 요일 기준을 카드 보조 근거로 사용한다. 실제 고립 정답이 없어 분류 정확도로 선택하지 않는다. 비교 관측·설명·재현성·원천 정합성을 기준으로 선택했다.

| 소스 | 입력 → 변환 | 최종 출력과 연결 | 해석 |
| --- | --- | --- | --- |
| 사회조사 I5 | 확정 V3 전국 성·연령 6집단, E/P/O/C/U 5영역 | 동결 survey_mois_reference 6개 CSV | 직접 조사한 전국 집단 참고값. 기존 50:50 지수와 혼합하지 않음 |
| MOIS | 지역·월 성·연령 인구구성 → 전국 I5 가중 | 별도 survey_area_isolation_index_v1: 시군구 12행·행정동 282행 | 지역 직접 조사값·고립률이 아닌 인구구성 기반 참고값 |
| SKT·신한 V3 | 월 관측 120셀 → 전월 Q, 지역·월 10집단 중앙값 H, T=Q-H → Rule/Robust | behavior_evidence 100행, 감소 후보 47·강건 후보 2 | Q/H/T는 동일 변화를 분해한 값. 고립 확률이나 독립 신호 3개가 아님 |
| 신한 C3 | 같은 data2 → 7~9월 비공휴일 동일 요일 중앙값 → 10~12월 월별 평가 | historical_reference 880행 중 동일 키·age_sex·all 24셀만 연결 | 같은 카드 원천의 다른 기준선. 분기 점수의 월 복제나 독립 검증자료가 아님 |
| 행정동 SKT | 기존 merge 공간 키 → 동·월·성·연령 집계 | dong_skt_evidence 2,820행, 카드 null | 관측지 활동 근거. 거주민 개인 고립도·행정동 카드 실측으로 확장하지 않음 |
| C1 / M1·M2 | C1 실제 JSON 분기 분석 / M1·M2 보존 완료 실행 해시 검증 | external_context에 별도 보존 | 원래 시간·지역 범위 유지. 행동 후보를 바꾸거나 월·지역으로 복제하지 않음 |
| M3 | SKT 원파일 18개 해시 검증 | not_comparable, 주 모델 조인 차단 | 공식 공간 매핑 확인 전 직접 결합하지 않음 |

현재 100셀에서는 원본 V3와 수치·판정·품질이 일치한다. 소스 결측 시 강건 통계가 다른 정상 소스까지 제거되던 경계조건은 로컬 코드에서 보완했다. 상세 검수는 [MODEL_FINAL_REVIEW.md](MODEL_FINAL_REVIEW.md), 원본 설명 연결은 [INTEGRATION_REPORT.md](INTEGRATION_REPORT.md)를 따른다.

채택 범위는 연구용 관측 변화 분석이다. 품질 hold·운영 경보 불허를 유지하며 공동 최종 동결은 대기 중이다.

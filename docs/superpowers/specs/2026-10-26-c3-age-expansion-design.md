# C3 20세 이상 연령 확장

사용자 요청: `hermes-complete/model/final_model`을 참고하여 현재 final 서버의 C3를 20·30·40·50대·60세 이상으로 확장한다. 성별을 포함한 10집단이며 아동·청소년 추가는 범위 밖이다.

참고 경로와 현재 서버의 C3 코드는 동일한 구버전이다. `submission/code/vendor`의 C3 1.1.0 확장 구현에서 연령 합산과 연결 부분만 이식한다. 전체 모델 복사는 별도 I5 표시·품질 계약을 바꾸므로 하지 않는다.

60·70·80·90대 원 건수·금액을 일별로 합산한 다음 7~9월 같은 요일 중앙값을 계산한다. `60+`를 V3의 `60GU`와 대응한다. V3 활동값, 기존 20·30대 C3 기준선·감소 판정, I5, 5% 활동 분류, hold 및 운영 제한을 유지한다. 평가 기간 밖의 C3는 null을 유지한다.

재계산은 별도 출력 디렉터리에 작성하고 기존 번들 해시, 기존 C3 값, 기대 연결 키, 원 월건수, 스키마를 검사한다. 원자료나 검증된 확장 번들 없이 신규 연령 값을 생성하거나 게시하지 않는다. 운영 번들은 검증된 결과가 있을 때만 교체한다.

확인한 입력 경계: 현재 신한 ZIP과 확장 번들이 로컬에 없다. 원자료 경로를 사용자에게 요청했으며 코드·재계산 도구·회귀검사를 먼저 준비한다.
